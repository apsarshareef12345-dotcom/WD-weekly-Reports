# WD Weekly Studio

Open index.html in a modern browser or upload this folder to a GitHub repository and enable GitHub Pages from the repository settings, deploying from the main branch root.

Enter a person's name, team and week, then enter minutes and save. Reports remain in the browser on the current device; they are not shared automatically across team members or devices. Download Excel files to share and back up your work. Excel export uses the SheetJS library from a CDN, so an internet connection is needed. Working days are days with any entered minutes; required minutes are 480 per working day. Team member counts are editable.
